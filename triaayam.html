Triaayam Catalogue

Triaayam provides 3d printing services and solutions.

My Role

As a Graphic Designer in this project I was asked to create a catalogue for triaayam.

Tool Used:
Photoshop
Project Period:
June'21
The Problem

Triaayam is a 3d printing services and solutions. For that they wants to show their products to their customer as conviniently as possible but in structured manner just like printer prints in layers connected to each other.

The Goal

To combine all product and categorized them to show case in a catalogue.

First Draft

Initially, to create minimal approch client want to display only one photo per category then encounter a problem that if we show only one photo per category then it will not properly give ideas about the products they can get in that category. So I use hexagonal shape rather then regular rectangle so that it will look more connected to each other like honeycomb and create more strong structure as well as it will give more room to add more products.
