Eatummy - Food App

Eatummy is an food app that lets user to find restaurant based on favourite cuisine. Eatummy allows user to select location and find the restaurants and also user can search via his/her cuisine. Eatummy has a feature to book a table at restaurant at prior and also user can order food at home.

My Role

This project is part of assignment of UI/UX course called UX Design fundamentals on coursera offered from callifornia arts institute. So in this project my role was as a UI-UX designer.

Tool Used:
XD, Illustrator, Photoshop
Project Period:
Sept'21 - Nov'21
The Problem

Now a days there are many apps for food ordering but there are one missing component which is cuisine. That's why user have to order one thing from one restaurant and second thing from another restaurant. usually by doing that users get their orders one after another. they have to wait for all items and not get the right taste.

The Goal

Main goal was to allow user to order different items in one go.

Design Steps
1. Mood Board
2. Sitemap
3. Wireframe
4. Final Design
